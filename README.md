Entry for the [make.fun bounty "One Letter for Your Day"](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

## What the program does

`main.py` (pure Python standard library, no network, no model calls)
writes exactly one letter to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).

## The letter

**K** — for **knackered**: utterly exhausted, drained to the last
drop. Not tired, not sleepy — knackered is the day that wrung you
out like a dishcloth and ended with you flat on the sofa, shoes
still on, phone face-down, staring at the ceiling. Vivid, funny,
and true: everyone has had a day that knackered them.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/letter-test python3 main.py
cat /tmp/letter-test/entry.txt  # K
```
